# BlueprintAI Execution Strategy & Plan

## Project Vision
BlueprintAI is designed to bridge the gap between idea and implementation for students and early builders. By leveraging MiniMax AI, we automate the tedious parts of product planning (Market Research, PRD, Wireframing, System Design).

## Tech Stack
- **Mobile**: Kotlin + XML Layouts
- **Backend**: Firebase (Auth, Firestore, Storage, Functions)
- **AI**: MiniMax AI API
- **PDF Generation**: Node.js (Firebase Functions)

## Roadmap & Milestones

### Phase 1: Foundation (Current)
- [ ] Firebase project setup and integration.
- [ ] Authentication flow (Google/Email).
- [ ] Firestore collection structure for Users and Projects.
- [ ] Basic UI: Login, Register, Home (Past Projects).

### Phase 2: Core Generation Engine
- [ ] MiniMax AI API key configuration.
- [ ] Sequential Prompt Chaining in Cloud Functions.
- [ ] Markdown to PDF conversion logic.
- [ ] Real-time status updates via Firestore ("processing" -> "done").

### Phase 3: Premium UI & Experience
- [ ] "Wait-less" UX: Real-time listener for generation completion.
- [ ] Tabbed Preview Screen for PRD, Wireframes, and System Design.
- [ ] In-app PDF Viewer integration.
- [ ] Smooth transitions and high-end aesthetics.

### Phase 4: Expansion
- [ ] Export to external tools (Notion, Google Docs).
- [ ] Regeneration logic for specific sections.
- [ ] Collaborative sharing.

## Success Metrics
- Average generation time < 45 seconds.
- User satisfaction with PRD quality (completeness and structure).
- App aesthetics rating (Premium feel).
